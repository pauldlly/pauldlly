# Public Projects 

### Multi-Method Option Pricing Engine

Quantitative finance project designed to price and compare financial options using several widely used analytical and numerical methods.

**Pricing methods:**

* Black-Scholes-Merton
* Cox-Ross-Rubinstein Binomial Tree
* Monte Carlo Simulation
* Finite Difference / Crank-Nicolson

**Technologies:**
`Python` `C++` `NumPy` `Matplotlib`

**Key results:**

* Option pricing using several independent methods
* Comparison of numerical results with Black-Scholes theoretical prices
* Analysis of convergence, accuracy and computational performance
* Calculation and analysis of option Greeks
* Implied volatility estimation
